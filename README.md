# 🛒 E-Commerce Sales Analysis Dashboard

## 📌 Overview
This project focuses on analyzing e-commerce sales data to evaluate overall business performance and identify key trends. The aim is to derive actionable insights related to sales, product categories, and regional performance.

---

## 🧰 Tools & Technologies
- Python (Pandas)
- SQL Server
- Power BI

---

## 🔄 Project Workflow

### 🔹 Data Cleaning
- Removed duplicate records
- Handled missing values appropriately
- Standardized date formats
- Created additional fields such as Month and Year for analysis

---

### 🔹 Data Analysis (SQL)
- Calculated total sales and number of orders
- Performed category-wise sales analysis
- Analyzed region-wise performance
- Evaluated monthly sales trends

---

### 🔹 Data Visualization (Power BI)
- Developed an interactive dashboard
- KPI Cards for Total Sales and Orders
- Bar Chart for category-wise comparison
- Line Chart for monthly trends
- Map visualization for geographical insights
- Added slicers for Year, Region, and Category filtering

---

## 📊 Key Insights
- Technology category contributes the highest share of sales
- Sales show a noticeable increase toward the end of the year
- Certain regions generate significantly higher revenue
- Early months show lower sales compared to later months
- A limited number of products drive a major portion of revenue

---

## 📁 Project Files
- `cleaned_sales_data.csv` – Cleaned dataset used for analysis  
- `analysis_queries.sql` – SQL queries for data exploration  
- `sales_dashboard.pbix` – Power BI dashboard file

## 🎯 Conclusion
This project demonstrates an end-to-end data analysis process, starting from data cleaning to building an interactive dashboard. It highlights how data can be transformed into meaningful insights to support business decisions.
